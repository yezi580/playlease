1. 产品概述

1.1 产品定位

面向《三角洲行动》（Delta Force）玩家的游戏账号 C2C 短租平台：号主（卖家）发布账号出租，玩家（买家）按天租用，平台居间担保交易——买家资金经汇付天下托管，履约完成后平台分账（扣佣、退押金余额、打款卖家），纠纷由客服裁决。附带「改枪码」免费分享页作引流内容。

1.2 角色定义

角色说明
买家租用账号的用户；手机号注册，同一账号可买可卖
卖家（号主）发布账号出租的用户；需完成汇付进件（开户+绑卡）才能线上收款
客服（support）平台员工；主站客服工作台处理售后/售前/商品审核/一切资金强操作
管理员（admin）平台管理；独立后台负责用户/订单/商品/参数/数据看板/审计

1.3 核心业务模式

  1. 资金托管：买家付款（租金+押金一次支付）进入平台汇付商户账户托管；「冻结」= 平台暂不退款/打款。汇付商户自动结算必须保持关闭。
  2. 双边定价：卖家发布租金 × (1+买家服务费率) 为买家实付价；额外物品卖家定价、买家侧可升价，差价归平台且双边互不可见对方价格。
  3. 押金冷静期：结算后押金不立即退，默认保管 3 天，期间卖家可举报买家开挂等违规，客服裁决没收赔付或驳回退回。
  4. 客服裁决制：取消、结算争议、资金冻结、押金举报四类纠纷全部由客服裁决，资金操作强制 Passkey 二次校验。

4. 业务规则汇总

4.1 定价与佣金

规则公式/取值
卖家租金哈夫币余额(M) ÷ 基础比例（比例 35-120，万哈夫币/元）
买家实付租金卖家租金 × (1 + 买家服务费率)，费率默认 10%（后台可配）
平台抽成（普通结算）floor(卖家租金 × 卖家服务费率) + 额外物品差价（买家价−卖家价，仅买家价更高时）
卖家入账max(0, 卖家租金 − 卖家佣金 − 保险费) + 出售物品款（卖家侧价）
保险费按赔付方案：premium 高级 9% / medium 中级 5% / basic 初级 0%（租金抽成）
买家退款（普通结算）max(0, 押金 − 买家侧物品扣款)
邀新返现买家服务费 × 30%（可配），结算时打款邀请人
额外物品双边定价：卖家结算价 + 买家结算扣款价；差价归平台；双方互不可见对方价格；「赠送」物品不结算

4.2 冻结裁决公式（资金冻结后按责任方）

责任方平台抽成卖家入账买家退款
卖家责任（默认）买家实付租金 + 物品差价仅物品款（租金归平台）max(0, 押金 − 买家侧物品扣款)
买家责任max(0, 押金 − 卖家侧物品款)买家实付租金 + 物品款0

物品款两种裁决下均照常结算给卖家；支持 payout_mode=manual（客服线下收款，强制备注留痕）。

4.3 超时与自动规则矩阵（后台可配）

场景默认值动作
待付款超时10 分钟查单→未付则汇付关单+订单取消+商品恢复上架
支付后未确认账号48h自动视为已确认（verified_at=paid_at）
租期结束未申请结算3 天自动进入结算中
买家未申报物品24h转客服仲裁
卖家未确认申报48h视为确认
资金冻结未处理48h客服工作台告警
押金举报未裁决48h（1-720 可配）客服工作台告警
押金冷静期3 天（0=关闭）到期自动原路退买家
取现单笔 ≤5 万、每日 5 笔D1 到账
上传配额100MB/天/用户超限拒绝

4.4 商品/订单状态联动

  • 商品被下单 → rented（锁定）；订单取消/完成 → 恢复 active；结算完成 → sold_out。
  • 审核驳回 → 商品 inactive，编辑重提后再进 pending_review。
  • 订单主状态 7 态：pending_payment → paid → settlement_pending → deposit_holding → completed，旁路 support_handling / 终态 cancelled（详见《开发设计文档》4.3）。

6. 范围边界与非功能需求

6.1 当前版本明确不做 / 未上线

项现状
购物车 / 多商品合并下单无，一单一商品
商品评价体系无
买家自助退款申请无；退款统一经「取消订单→客服」或结算退款
商品关键词模糊搜索仅完整商品编号精确搜索
续租租期固定；归还=申请结算
代肝板块入口占位，提示「开发中」
公告 / 站内信管理无管理端模块（站内通知仅系统事件触发）
批量操作 UIstep-up 字典预留 batch_operation，无界面
提现管理后台 UI操作日志预留 wallet 模块，无界面
微信登录 / 微信支付无集成；微信仅作联系字段与敏感词屏蔽对象
实名认证 FaceID已从主链路移除（卖家走汇付进件实名）
管理端订单列表分页暂无（固定 20 条/页），商品列表已补分页

6.2 非功能需求摘要

类别要求实现（详见《开发设计文档》）
性能列表页响应快、读多写少Redis 详情缓存 180s、7 日热度预聚合表、复合索引、gzip、静态资源 1 年强缓存、WebP 变体降流量
可用性发布零停机、支付回调不丢蓝绿双容器 + 健康检查门槛 + 优雅停机；支付结果三路兜底（回调/轮询查单/超时任务）+ 120s 资金对账
资金安全任何状态不入错账金额一致性校验、状态守卫 UPDATE、reason/remark 幂等键、对账收口、商户自动结算关闭约束
防刷短信/注册/发布/上传天御验证码前置、双层限流矩阵、日配额、DB 频控计数表

术语含义
改枪码三角洲行动武器配装分享码（平台免费内容页，引流用）
哈夫币游戏内货币；商品定价锚（余额 M ÷ 基础比例 = 租金）
基础比例万哈夫币/元的换算系数（35-120）
